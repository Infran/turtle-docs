# Turtle Ecosystem Documentation & Public Roadmap 🐢

Welcome to the public documentation and specification hub for the Turtle platform.

## Overview
Turtle is a modern modular ecosystem comprising financial management, messaging services, CLI automation tools, and release infrastructure.

## Repositories
- **`turtle`**: Core Web application, Go backend, and UI/i18n libraries.
- **`message`**: Messaging backend microservice (Go + Gleam).
- **`messager`**: Cross-platform messaging mobile application (Flutter).
- **`messager-web`**: Web messaging application (Angular 22).
- **`cli`**: Developer & ecosystem CLI utility.
- **`release-server`**: Deployment and release distribution service.
- **`turtle-i18n`**: Standalone translation and localization package.
